# Images par défaut

Ce dossier contient les images par défaut du forum TwitchNerd.

## Images nécessaires :
- default-avatar.png : Avatar par défaut (50x50px)
- default-article.jpg : Image d'article par défaut (400x200px)

## Recommandations :
- Utiliser des images optimisées pour le web
- Formats recommandés : PNG pour les avatars, JPG pour les articles
- Taille maximale : 2MB par image
- Résolution : 72 DPI

## Images par défaut suggérées :
- Avatar : Icône utilisateur générique ou logo Twitch
- Article : Image de fond avec logo TwitchNerd ou image gaming/streaming
